# index-me

Подход к работе с ИИ агентами, который гласит "не нужно читать всё - нужно индексировать скриптом и вычитать главное".

Вместо того чтобы читать огромный контекст - сделать скрипт, который попилит контекст на цельные куски и создать оглавление по нему.

Либо разработать скрипт, который будет этим самым поисковиком и оглавлением. Получая на вход запросы будет отдавать куски которые с ним связаны.

## Артефакты

Результатом такого подхода должны быть:
1. ЛИБО большой файл, который порезали на маленькие и создали к ним оглавление. Процедура разделения делается **НЕ РУЧНУЮ** а путем написания скрипта.
2. ЛИБО вместо разбиения большого файла создан скрипт, который вычленяет информацию и по сути делает это "разбиение" на лету в каком-то смысле. Представь что мы пишем скрипт не который пилит файлы, а который умеет по большому файлу искать нужное.

Вариант 2 предпочтительнее для регулярного разбора подобных файлов, а не разовой задачи, потому что выявление закономерностей для создания поисковика оверхед для одноразовой задачи.

## Начало диалога

Попробуй по роду задачи понять чем занимается юзер (например создание скилла явно для постоянных задач история, а разбор бага - разовая акция).

Если однозначно понять не получается - остановись и спроси. Если сомневаешься лучше спроси.
